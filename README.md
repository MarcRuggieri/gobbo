# Gobbo

Un gobbo (teleprompter) che sta in una pagina web: leggi i testi, correggili e registrati con la camera mentre il testo ti scorre davanti e segue la tua voce. Niente da installare: funziona in Chrome e Safari, sul Mac e sul telefono.

- I testi sono cifrati (AES-GCM) in `testi/`: si aprono solo con la chiave che sta nel link, dopo il `#` (il server non la vede mai).
- Le registrazioni restano nel browser di chi registra finché non le scarica.
